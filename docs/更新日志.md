## v1.x　网页版（离线查询）

### 1. 拿到"真数据"：从客户端配置里解密，而不是抄攻略

- **问题**：攻略站的棋子表互相矛盾，星级/数值/概率经常是旧版本的。
- **调查**：Steam 版《三国杀》其实是 CEF 套壳（`Sgsc10th.exe` + `libcef.dll`），真正的内容在 `web.sanguosha.com`。打开 `browserCache` 发现配置包 `Config.sgs`，里面的文件是加密的。
- **原理**：客户端用 `CtrUtil.Ctr.Ofb_Dec`（WebAssembly 模块 `resc`）做一次 OFB 流解密。
- **解决**：`tools/update_data.py` 用 Python 的 `wasmtime` 把同一个 wasm 跑起来，调用它的导出函数对 `.sgs` 做同样的一次解密 → 得到明文 JSON（`TavernChessConfig.sgs`）。
- **结果**：棋子/主公/锦囊/装备/营帐概率/经济参数全部是当前版本原样数据；新赛季重跑脚本即可。

### 2. `.sgs` 解出来是 gzip

- **问题**：解出来后 `json.loads` 报 `0x8b` 解码错误。
- **原因**：`.sgs` 有的直接是 zip（`Config.sgs`），有的是 gzip（`TavernChessConfig.sgs`）。
- **解决**：解密后按魔数判断：`PK` 当 zip、`1f 8b` 先 `gzip.decompress`、`{`/`[` 直接当 JSON。

### 3. 评分被"牌多"带偏

- **问题**：最初"协同/经济"用牌数直接除以常数，结果牌最多的群势力分数虚高。
- **解决**：改成"密度 + 封顶"（`min(1, 张数/6)`），并把各星级按重要度加权（1★ 0.08 → 4★ 0.22），缺星级的势力自然被扣分（比如群没有 1★ 过渡牌）。

## v1.2　游戏内浮窗（注入版）

### 4. 怎么把界面塞进游戏里

- **调查**：客户端是 Chromium 套壳 → 用 `--remote-debugging-port=9222` 启动就能通过 CDP 注入 JS。
- **解决**：`game_overlay/launch.ps1` / `inject.mjs` 负责启动 + 注入 + 断线重连（`Page.addScriptToEvaluateOnNewDocument` 保证换页后仍然生效）。
- **踩坑**：PowerShell 5.1 读 `.ps1` 按 ANSI 解码，中文注释会把文件解析坏 → **脚本必须存成 UTF-8 with BOM**；另外 `if (-not Test-Port)` 要写成 `if (-not (Test-Port))`。

### 5. "我明明进了自走棋，浮窗却不见了"

- **原因**：只在 `TavernChessGameScene` 且带 `manager` 时才显示，而**大厅/房间**是 `TavernChessHallScene`，没有 manager。
- **解决**：大厅也显示"待机卡片"（证明助手活着），进对局自动切完整面板。

### 6. 场景识别抓到子节点

- **问题**：进对局后面板变待机，读不到数据。
- **原因**：场景树里有大量 `TavernChess*` 节点（窗口、按钮），深度遍历先命中的不是游戏场景。
- **解决**：改成**按权重打分**挑场景：`TavernChessGameScene`(100) > `TavernChessHallScene`(80) > 任意 `TavernChess*`(10)，带 `manager` 且能读到 `shopGoods / chessMinionTypList` 的再 +70。

### 7. 商店数组里有空位导致渲染崩溃

- **问题**：面板白屏/不刷新。
- **原因**：`shopGoods` 里存在 `null` 空位，`map` 之后直接取 `.name` 抛异常。
- **解决**：`normalizeGoods` 对空值返回占位对象；渲染前统一兜底；并把异常写进 `window.__zzqError` 方便排查。

### 8. 读不到局面的字段名不一致

- **调查**：不同版本的客户端字段有大写/小写差异（`ShopGoods`/`shopGoods`、`HandChess`/`handChess`、`lineUpChess`/`LineUpChess`）。
- **解决**：所有读取都写成"多候选 + 兜底"：`mgr.ShopGoods || mgr.shopGoods || self.ShopGoods…`，并在 `findManager` 里用 `ReqShopRefreshChess / shopGoods / playerList / selfInfo+CoinNum` 作为"这是一个 manager"的判定特征。

### 9. 热更新：改完代码不想重启游戏

- **解决**：`overlay.js` 里加 `VERSION` 常量 + 重复注入时清理旧面板/定时器；`game_overlay/push.mjs` 直接把新代码推进正在运行的游戏。以后改代码 → `node game_overlay/push.mjs` 即可。

## v2.x　决策能力

### 10. 站位建议

- **做法**：按技能触发时机给 1~7 号位排序：开战/当先/破军 → 遗计/阵亡 → 咆哮 → 光环 → 常规 → 功能（不攻击） → 经济；再和玩家当前排列做 diff，直接告诉你"把谁从几号位挪到几号位"。

### 11. 对手面板：客户端根本不给对手阵容

- **调查**：`playerList[i]` 里别人只有 `hp/shopLevel/generalID/equipments`，`Chess` 字段只有自己那份。
- **解决（第一版）**：用**主公**反推流派（主公的势力限制 + 技能里点名的势力），算"抢牌压力"，再决定"继续抢主线"还是"改投冷门势力"；同时用血量标出 🔥威胁 / ⚠可送走。
- **后续（v5 记录器）**：对局中客户端会下发"本轮对手"的棋子（战斗要渲染），所以能**在对局里抓到别人阵容**并记录下来，见下。

### 12. 三选一建议

- **调查**：候选项在 `waitSelectCardArr` / `WaitSelectCards` / `waitSelectEquiments` 里，结构是 `{CardVO, ServerInfo{goodsID,chessID,spellID}}`。
- **解决**：做了多字段兼容 + "场景兜底扫描"（找类名含 Select/Choose 且挂了 3 个候选的节点），按"主推阵营 / 能不能直接三连 / 星级 / 是否本局势力"打分。

### 13. 官方阵容库：接接口

- **调查**：游戏内「阵容推荐」走 `https://yjcm-zzq.sanguosha.com/v1/recommend`。为了知道参数和签名，把主程序 `sgsGame.sgs` 下下来解密成 `main.min.js`，找到：
  - 参数：`account / country / tag / general_id / timestamp`
  - 签名：`md5(按 key 升序拼 "key=value" + apiKey)`
  - 字段：`win_rate / front_rate / users / likes / early·middle·last / general_note…`
- **解决**：写了个 `fetch_lineups.py` 直接抓（当时 S11 有 3 套官方阵容）。
- **后来按你的要求**：官方库两度降级，最后**整套删除**（面板不再引用、文件也从仓库移除）——只有 3 套固定阵容、不结合本局阵营/牌池/对手，参考价值太低。

## v4.x　牌库 + 阵容原理

### 14. 牌库份数

- **数据**：`ChessRankConf.TotalCount` = 每张牌在公共池里的份数（1★18 / 2★15 / 3★13 / 4★11 / 5★9 / 6★7）。
- **面板**：按星级列出本局可用势力的每张棋子，标"池中份数 / 你持有 / 本局商店出现过几次"，可切换"只看主线 / 看全部"。
- **为什么不是精确剩余数**：客户端不下发公共池的实时状态，"别人手里几张"看不到，所以用"本局出现次数"当代理指标。

### 15. 阵容推荐改为"按原理生成"

- **做法**：为每个本局可用势力生成 7 人成型阵容（`6★×2 + 5★×2 + 4★×2 + 3★×1`，缺则顺延），并逐条给原理：核心依据（引用技能原文）、曲线与三连（各星级候选牌数 × 份数）、经济牌、成长/光环牌、前期过渡牌、节奏。

## v5.x　对局记录 + 冠军阵容

### 16. 记录器

- **记录内容**：本局阵营、我的主公、每回合（虎符/营帐/血量/商店出现过哪些牌/我的阵容）、最终阵容、结束时的名次、结束时每家状态。
- **别人阵容**：战斗阶段客户端会下发本轮对手的棋子（`enemyPlayerInfo.Chess`），另外战斗舞台的 `enemyUIs` 里也有 `ServerInfo.chessID`；两路都尝试，取更完整的那个记录下来。
- **存储**：先写 `localStorage`，注入器（`inject.mjs` / `launch.ps1`）每 10 秒把 `window.__zzqExportMatches()` 拉回本地 `records/matches.json`。

### 17. 统计汇总

- `tools/summarize_records.py` 把记录汇总成 `data/stats.js` + `记录报告.md`：
  - 我的：总场次/平均名次/前四率/吃鸡率，按势力、按主公、按具体阵容分组；
  - 别人的：**每局结束时唯一没死的那家（= 冠军）**的阵容，聚合成"冠军阵容榜"；以及对手阵容里出现最多的棋子。
- 浮窗把统计读回来显示在「战绩统计」里；同一势力打过 ≥5 局后，会用它微调该势力的推荐分（权重压得很小，样本少时几乎不影响）。

### 18. "我正常开游戏时浮窗不会自动出现"

- **现象**：只有走 `启动并注入.bat` 才有浮窗；从 Steam 点开始游戏时什么都没有。
- **原因**：CEF 的调试端口只能在**启动时**用 `--remote-debugging-port` 指定，而且光有端口还不够 —— 还要有人把脚本注入进去。以前这两件事只有手动脚本一起做了。
- **排查**：查当前游戏进程的命令行，发现 `Sgsc10th.exe --remote-debugging-port=9222`，父进程是 `steam.exe` —— 说明 Steam 的启动参数里**已经**带了端口（`userdata/<id>/config/localconfig.vdf` 里该 appid 的 `LaunchOptions`），缺的只是"端口开了以后自动注入"。
- **解决**：新增后台监视器 `game_overlay/auto-watch.ps1`：
  - 每 3 秒检查 `Sgsc10th.exe` 与 9222 端口；
  - 端口通 → 自动拉起注入器（`launch.ps1 -NoLaunch`，隐藏窗口），并在托盘弹提示；
  - 端口不通但游戏是刚启动的（默认 150 秒内）→ 自动带参数重启游戏（兜底：万一哪天 Steam 启动参数被清掉）；
  - 端口不通且游戏已经跑了很久 → 只弹提示，绝不擅自杀掉正在进行的对局；
  - 游戏退出 → 自动停掉注入器子进程，不留后台垃圾。
- **开机自启**：`安装自动启动.bat` 会在启动文件夹放一个 `.vbs`（用 `WScript.Shell.Run ..., 0, False` 隐藏窗口拉起监视器），并立刻启动一份；`卸载自动启动.bat` 负责清理。
- **踩坑**：`.vbs` 里含中文路径，必须存成 **UTF-16LE(带 BOM)**，否则 wscript 按 ANSI 读会把路径读坏；`.ps1` 仍然要 UTF-8 with BOM。
- **验证**：关掉游戏 → 用 `steam://rungameid/1180320`（等价于在库里点"开始游戏"）→ 监视器日志出现"端口已开，启动注入器"→ 新实例页面里 `window.__zzqOverlayVersion = 5.1.0`、棋子数据 185 张、记录器就绪，端到端通过。

### 19. 阵容推荐"只有一套、而且不会拼别家棋子"

- **现象**：面板每个势力只给一套"清一色"阵容，玩家换不了；也没告诉玩家这局到底该走哪套。
- **原因**：旧逻辑只是"按星级+数值从同一势力里挑高分牌"，没有机制概念，自然拼不出配合，也解释不了为什么强。
- **解决**：新写一个阵容引擎 `game_overlay/engine.js`：
  1. 用关键词把 185 张牌打成机制标签（判定/受伤/志继/当先/招募结束/遗计/随征/护甲/冲阵/御策/功勋/伤害计数/回手/闪避/挑衅/经济/万能…）；
  2. 定义 8 套阵容原型，每套按 **前期打工 → 中期引擎 → 5★核心 → 6★收尾** 列候选，保证曲线合理、前期能站住；
  3. **跨阵营插件**：放大器（祢衡/刘表/于吉/周瑜/马岱）、触发桥（张郃/黄盖/徐盛/于毒/何太后/张楚/何进/赵襄/张燕）、万能牌（左慈/鲁肃/袁术）——这些才是"别家棋子补强主线"的真实打法，插件只从本局可用阵营里选，且只替换阵容里最弱的一张；
  4. 每局输出 **2~3 套**，标注"刷牌型 / 成型型"，附 7 人成型、前期过渡、主公推荐、节奏、弱点，并按"你已有几成 + 吃鸡记录 − 抢牌压力"排序；
  5. 新增**克制矩阵**：按打法风格 + 特殊克制表算推荐阵容之间的优/劣/五五，并给出原因。
- **验证**：`node tools/test_engine.mjs`（可传阵营，如 `1,3,5,6,7`）离线检查阵容质量；再在游戏里用 `push.mjs` 热更新看实机面板。
