④ 推荐打法

⑤ 目标：保前四 / 争第一

保前四（稳分打法）

全程优先战力即时性：营帐等级跟上大部队即可，能赢就赢，血量健康时不用为了吃鸡赌大牌。
每回合留 1~2 张能立刻上场的对子，宁愿吃 2 星打工牌也不要空着位置。
血量低于一半后停止存钱：该刷新刷新、该升营帐升营帐，先把命保住。
观察同桌中同样在抢你主力的玩家：超过 2 家就换次优阵营，避免三家分牌池。

争第一（上限打法）

前中期用低星对子保血，把虎符留给 5~6 星核心，等拿到核心再一口气吃三连升金。
金色卡 = 3 张同名 + 额外三选一，收益远大于多上一张杂牌，所以主力阵营的牌别随便遣散。
装备（第 3/7/11 回合）尽量集中在 1~2 个能持续吃属性的核心身上。
残局（剩 2~3 家）看对手阵容调站位：先手位给开战/当先卡，遗计/阵亡收益卡往前放，经济卡藏后面。

对局阶段与机制

数据是怎么来的

本工具的数据不是抄攻略，而是直接从《三国杀·一将成名》客户端（Steam 版《三国杀》也是同一个网页端内核）拉取的官方配置：

  1. 下载官方资源站的 Config.sgs 配置包与 resc 解密模块；
  2. 用本地跑起来的 wasm 模块做一次 OFB 解密，得到明文配置；
  3. 取出 TavernChessConfig.sgs（酒馆自走棋配置），解析成棋子、主公、营帐概率、经济参数。

所以棋子数值、技能描述、概率表、主公技能这些都是当前版本的原样数据，赛季更新后重跑一次脚本即可刷新。

关于“每局禁用阵营”

客户端配置里并没有写死“禁 2 个”，而是服务端在开局时下发本局阵营列表 （协议字段 chessMinionTypList，注释就是“本局阵营”）。 人机/新手自定义的默认值是 4 个阵营、其余为锁定（不出现）。 所以你只要按游戏里开局界面实际显示的几个势力在工具里点选即可，工具会自动只在这些阵营里给你排名和建议。

游戏内浮窗版（像小抄一样贴在游戏里）

同一个客户端是 Chromium 套壳，所以可以像「小抄」那样注入一段脚本，直接在游戏右上角显示助手：本局阵营、商店每张牌该不该买、三连进度、该升营帐还是该刷牌。

  1. 双击本文件夹里的 启动并注入.bat（它会用调试端口启动客户端并自动注入）；
  2. 进入自走棋，右上角出现「🎲 自走棋助手」面板；拖动标题栏可以移动，Alt+H 隐藏/显示；
  3. 想先看效果又不想开游戏：直接打开 game_overlay/demo.html，那是用假局面渲染的同款浮窗。

浮窗是只读的：只读取本局阵营/商店/手牌/虎符并给建议，不会替你买牌或刷新。

怎么更新数据（新赛季/平衡性调整后）

  1. 确保装了 Python 3，并执行一次 python -m pip install wasmtime；
  2. 在本文件夹下运行 python tools/update_data.py，它会自动联网拉最新配置并重写 data/tavernchess.js；
  3. 重新打开本页面即可。

如果下载失败，也可以自己另存 https://web.sanguosha.com/10/pc/res/config/Config.sgs，然后运行 python tools/update_data.py --config 路径。

数据来自游戏客户端配置表，仅供个人理解机制与决策参考。打牌的是你，不是我。
