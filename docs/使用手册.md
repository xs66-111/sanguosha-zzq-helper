# 使用手册

## 一、最快的路径

1. 双击 `启动并注入.bat`（首次需装 Python 3 并执行一次 `python -m pip install wasmtime`）；
2. 进游戏 → 自走棋 → 打一局；
3. 右上角出现「🎲 自走棋助手」，顶部标题栏可拖动，`Alt+H` 隐藏/显示，右侧「收起」折叠。

不想开游戏也能看效果：打开 `game_overlay/demo.html`（用假局面渲染的同款浮窗）。

## 二、面板各区块

| 区块 | 说明 |
|---|---|
| 本局阵营 / 主推 | 服务器下发的本局势力，金框=本局最强主线 |
| 局面 | 回合、营帐等级（含当前升级价）、虎符、主公、体力 |
| 阵容推荐（按实战原理） | 每个候选势力的 7 人成型阵容 + 核心依据/曲线三连/经济/过渡/节奏 |
| 牌库 | 本局可用势力每张棋子的池中份数、你持有几张、本局商店出现过几次 |
| 战绩统计 | 你自己打的场次/平均名次/前四率/吃鸡率 + 别人的冠军阵容 |
| 选主公建议 | 只在选主公阶段出现，按本局势力过滤后的推荐 |
| 选牌建议 | 三选一（锦囊/武将/装备）弹出时的 `选这个/次选/不选` |
| 商店 | 每张牌的 `必买 / 可买 / 凑对子 / 攒钱买 / 不买` + 理由 |
| 站位建议 | 1~7 号位建议顺序 + "把谁挪到几号位" |
| 对手 | 八家血量/等级/主公/装备，🔥威胁与 ⚠可送走；本轮对手是谁 |
| 三连进度 | 手牌+场上 几/3 |
| 现在该干嘛 | 按回合/虎符给的运营提示 |
| 官方阵容库 | 默认收起，仅参考，不参与推荐 |

## 三、数据更新

```bash
python -m pip install wasmtime        # 首次
python tools/update_data.py           # 赛季/平衡性更新后：重抓配置
python tools/fetch_lineups.py         # 可选：重抓官方阵容库
python tools/summarize_records.py     # 汇总你自己的对局记录
```

Win 下也可以直接双击 `更新数据.bat`。

## 四、对局记录

- 记录自动进行，存在游戏页面的 localStorage；注入器每 10 秒导出到 `records/matches.json`。
- 想清空：游戏控制台执行 `__zzqClearMatches()`；想手动导出：`__zzqExportMatches()`。
- 记录里含昵称等个人数据，默认不进 git（`.gitignore` 已排除 `records/matches.json`）。

## 五、常见问题

**Q：面板不出现？**
A：先确认在大厅/对局里（登录页没有自走棋场景）。仍不出现就 `F12` 看控制台有没有 `[自走棋助手]` 报错，或看 `window.__zzqError`。

**Q：数据读不到 / 显示 `?`？**
A：官方改过内部字段名。改 `overlay.js` 的 `readState()`（字段都做了多候选，照葫芦画瓢加一个即可），然后 `node game_overlay/push.mjs` 热更新。

**Q：注入器报"没找到可注入的页面"？**
A：游戏要先用调试端口启动。脚本会提示你先关掉旧客户端再重开。

**Q：会不会影响游戏 / 被封？**
A：本工具只读：不发送游戏协议、不自动操作、不改数据。它属于第三方注入，规则风险请自行评估。
